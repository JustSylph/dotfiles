Sylph Dotfiles
==============

Package List
------------
* filezilla
* vim
* kitty
* gh
* xorg
* fish
* i3
* polybar
* fastfetch
* feh
* curl
* firefox-esr
* pipewire-audio
* blueman
& dependencies

install.sh
----------
* Installs above packages
* Symlinks ~/.dotfiles/.config to ~/.config
* Symlinks DepartureMono-Regular.otf to /usr/share/fonts/DepartureMono.otf
* Changes shell to Fish

.xinitrc
--------
* Sets tiled wallpaper
* Runs blueman & pipewire-audio
* Runs polybar
* Starts i3
